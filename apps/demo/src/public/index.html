HONEST BOUNDARIES

What this build does not claim.

This local demo uses PostgreSQL tables and deterministic retrieval, not a hosted control plane or an LLM. Redis and pgvector adapters require live-service qualification.

No universal leak-proof guarantee, GDPR certification, production SLA, or validated market size is implied. Identifiers and audit metadata can be personal data.
